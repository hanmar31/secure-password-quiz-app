# Secure Password Quiz App

## Vision
The Secure Password Quiz App is an interactive educational web application designed to challenge the common misconception that a password is safe because it follows a website's rules. By combining a live password rule checker with hands-on quizzes, it teaches users the difference between following a website's rules and a password actually being safe.
## Requirements
- **R-1:** The app should allow the user to type a password and show, step by step, which rules the password follows and which rule it still fails.
- **R-2:** The app should give the user a confirmation when a password follows all the rules.
- **R-3:** The app should present quiz questions about what makes a password safe, one at a time and in random order.
- **R-4:** When the user answers a quiz question, the app should give immediate feedback explaining why the chosen answer is right or wrong.
- **R-5:** The app should allow the user to generate a password and see its score and strength label.
- **R-6:** After the user has generated a password and seen its score, the app should ask whether the password is guaranteed to be safe, and explain that it is not.
